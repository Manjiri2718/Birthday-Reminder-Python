# Birthday-Reminder-Python
📌 Project Description

Birthday Reminder is a simple Python-based project that helps users store and manage birthday information.

The program allows the user to add birthdays, view saved birthdays, search for a particular birthday, and check upcoming birthdays.
🎯 Objectives
To store birthday information.
To view all saved birthdays.
To search for a birthday by name.
To display upcoming birthdays.
To understand the use of Python functions, lists, dictionaries and loops.
To create a simple menu-driven Python application.
